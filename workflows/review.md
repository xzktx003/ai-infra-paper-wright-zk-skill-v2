# 写后逆向审查

## Pass 1 · 逐主张反查

从摘要和贡献列表往回找证据。给每条主张状态：支持充分/条件缺失/证据仅局部/未支持/与材料冲突。报告原句、定位、问题、最低修改或验证动作。不要只写“创新不足”等不可执行判语。

## Pass 2 · 叙事逻辑

检查 P2 的缺陷是否在 P3 被验证，P3 是否真的导出 P4 的设计要求。两个 motivation 是不同根因还是同一问题反复表述？第三个模块是主创新还是辅助？理论属于生成/保证/解释哪种角色？图表是否承担了自己没有证据支持的功能？

## Pass 3 · 比较公平性

核对同 checkpoint、数据、校准样本数、恢复预算、实际 bit、teacher成本、硬件、服务负载和生成设置。原文 reported 与自复现分列。不同起点的最终分数不能证明后优化模块更好。

## Pass 4 · 机制与边界

相关性是否被说成因果？局部代理是否被说成模型行为？理论量词是否被删？只报平均分是否掩盖困难域失败？不存在 GPU 实现时是否仍写实际加速？

## Pass 5 · 语言与版式

逻辑锁定后再删空话、重复定义、过度缩写和宣传式措辞。中文段落应有主句、证据和推理连接；不要每段都“首先/其次/最后”。保留必要不确定性。正文篇幅按当年官方规则和核心贡献分配，不为了模板凑固定自然段。

涉及摘要、引言、Motivation 或贡献陈述时，按 [开篇信息组织契约](../references/opening-sections.md) 检查（中英文通用）：

1. **OS1 技术区别**：删除后是否只剩方法名？必要公式、约束、实现和收益条件是否被误删？
2. **OS2 论证推进**：重复是在补机制/证据/条件，还是只在换名？指出重复位置与各自新增信息。
3. **OS3 操作对应**：困难是否导出具体操作，操作作用是否解释清楚？不能为简洁切断中间诊断。
4. **OS4 贡献**：是否列出真正新增的内容和范围，而非凑条数或罗列实验名？
5. **OS5 边界**：删的是编辑性辩解，还是会改变结论的限定/负结果？后者必须保留。
6. **OS6 证据等级**：是否用“错配”等标签替代根因证据，或把一个观测直接写成机制已证实？

只报告实际发现的问题及最小修改，不为六条规则各凑一条意见。验收看解释完整性和信息推进，不看压缩字数；局部改句不重跑全仓库诊断。

## Pass 6 · 英文散文（仅英文主会稿）

中文初稿跳过本关。英文 ICLR/ICML/NeurIPS 稿在 Pass 1–5 之后加载 `english-prose/prose-contract.md`；若本次是润色任务，按 `english-prose/polish-workflow.md` 的顺序改，而不是按 14 条清单乱序改词。本关不替代证据审查，也不能把文采不足写成科学错误。

按段落检查，只报原句、规则 ID、最小改法：

1. **A 术语（P12/P09）**：技术名词是否首次定义且后文未用禁止近义？对照项目 glossary。
2. **B 话题链（P01/P02/P07）**：换主语/换段是否带因果/递进/转折/对比？
3. **C 指代与句核（P14/P15/P16）**：`this/it/which` 能否换成唯一名词？已知是否在前、一句是否只推进一步？
4. **D 范围用词（P17）**：`better/improve` 是否有对象？`show` 是否强过证据？
5. **E 段落与时态（P06/P05）**：论证段是否有功能句；机制现在时、操作过去时；不硬用过去完成时。
6. **F 语域（P11/P03）**：目录句、营销词、前者后者。
7. **G 多样（P10/P13）**：只在相邻重复时换连接词/动词；名词不换。
8. **H 校对（P04/P08）**：语法、冠词、所有格，不打品味分。

冲突时：证据契约 > 术语冻结 > 连接与焦点 > 文采。

## 输出

按“阻断核心主张/影响解释或公平性/表达修正”分类，而不是给录用概率。每项有具体原句及修复动作。最后列当前可外发结论和仍需验证的结论；作者需复核机器审查，机器也可能漏错或误报。
