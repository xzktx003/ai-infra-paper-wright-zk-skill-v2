实际输出：

观察：保留倍率、排序不变、固定宽度交换和有限下游增益；未删第二阶段，也未把代理保证改成任务保证。

## B · 英文量化概述

实际输出：

Unlike the weight-space objective \(\min \|W-Q-AB\|_F^2\), this objective accounts for the input covariance, so residual directions need not contribute equally to the error. Under a positive-definite input covariance, we derive an analytical solution for the low-rank correction.
