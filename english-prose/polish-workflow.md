# 英文主会稿润色流程

来源：作者常用的 ICLR / ICML / NeurIPS 英文润色清单（14 条）。本文件把它收成**可执行顺序**，不是官方征稿条款，也不能用文采覆盖证据。

触发：用户要求润色、改英文、过 ICLR 文风、检查主语/术语/时态，或 `revise` 英文主会稿。先读本文件与 `prose-contract.md`；需要钉词时读 `glossary.md`；换连接词时读 `connectives.md`；按章节改口吻时读 `section-voice.md`。

## 0. 先分清三件事

| 问题 | 答案 | 本流程是否处理 |
|---|---|---|
| 是否符合 ICLR/ICML/NeurIPS **官方**要求？ | 看当年征稿页：页数、匿名、模板、Reproducibility / Ethics / AI Use | 否。格式不合去改 `main.tex` / 声明，不靠润色 |
| 主张是否站得住？ | `evidence-contract.md` | 否。数字、首次、加速不能为流畅而改强 |
| 英文是否像主会论证？ | 下面的检查簇（原 14 条已压缩，见 `rule-coverage.md`） | 是 |

润色顺序（不可颠倒）：

```text
冻结名词 → 话题链（主语/连接/段间）→ 指代与句核
→ 比较与表态动词 → 段落功能与时态 → 语域
→ 动词/连接词仅在重复时替换 → 语法与冠词校对
```

**名词冻结永远先于“写得多样”。** 先换 `joint selection` / `joint decisions` 再谈文采，等于把论文改坏。

## 2. 一次润色怎么做

对用户指定的范围（默认：摘要 + 引言 + 方法开篇 + 实验解释段；公式推导可后做）：

1. **指代与句核。** 每个 `this/it/which` 写出它的名词；范围前置，一句只推进一步。
5. **比较与表态。** `better/improve` 补出对象；过强的 `show` 改 `suggest` 或补证据。
6. **段功能与时态。** 论证段写出一句 topic；`evaluate/report` 现在时，`used/calibrated` 过去时。不要为清单插入过去完成时。
7. **多样。** 只替换重复的动词和连接词；名词表一个都不动。
8. **校对。** 语法、冠词、evaluate/report/attain`（现在，对读者仍成立）vs `used/trained/calibrated`（过去，一次性操作）。
6. **句核。** 删句尾的装饰性逗号短语；范围限定若是证据，改放到句首。
7. **多样。** 只替换重复的动词和连接词；名词表一个都不动。
8. **校对。** 语法与所有格。

输出格式（不要打「像顶会」分）：

```text
[段落定位]
- P12 原句：...
  改：...
- P02 原句：...
  改：...
保留未改的限定：...
```

一次改动必须能指回规则 ID。改完若页数被撑破，优先删重复句，不删 glossary 里的定义句。

## 3. 发挥：主会英文真正在惩罚什么

14 条里审稿人最容易感到「不像 ICLR/ICML/NeurIPS」的，通常不是所有格，而是：

1. **同一对象三个英文名**（P12）——读者以为有三个模块。
2. **主语跳接、句号当逻辑**（P01/P02）——像中文提纲英译。
3. **未定义就使用的机制词**（P12）——`stall`、`envelope`、`legal scale` 突然出现。
4. **把局部数字写成口号**（与证据契约冲突）——润色时若发现这种句子，降强度，不要润得更满。

过去完成时、主题句、关联词同义替换是加分项，不是拒稿项。不要为了清单硬插 `had` + 过去分词。

## 4. 明确禁止的“润色”

- 把 `joint selection` 换成 `joint decisions` 以“多样”。
- 删掉 `on Qwen3-4B`、`at about 2 bpw`、`on the same initialization` 让句子更干净。
- 把 `attains the lowest PPL.AVG on five of six models` 改成 `consistently outperforms`。
- 给方法节每段加 `In this paragraph, we...`。
- 用 `significantly`、`powerful`、`novel framework` 填空。
- 把中文「即 / 也就是 / 换句话说」译成连续三个英文同义词。

## 5. 与章节口吻

细节见 `section-voice.md`。摘要允许信息密度高，但仍要：一个问题、一个困难、一个方法名、一个条件性结果。引言论证段要主题句。方法推导段可以 `Let` 起句。实验解释段现在时报告表格，过去时只用于校准/训练等已发生操作。
